# MoneyTracker

App de finanças da casa e pessoais, para usar no celular.

- **Casa**: contas compartilhadas, quem pagou cada uma e quanto % cada um pagou no mês.
- **Eu**: entradas e saídas pessoais. Só o dono vê.
- **Categorias** e **Dívidas** (parcelamentos).

Site estático (sem build): `index.html` + ícones + `manifest.webmanifest`.
Dados e login no Supabase (projeto "Minhas Financas"), com regras de acesso por usuário.
